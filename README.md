## 사업성분석 자동화

단지별 입력 파일(TOML) 하나만 채우면 블로그 원고 초안, 엑셀 표, 민감도 차트가 한 번에 나옵니다.

```bash
python analysis/feasibility.py analysis/complexes/mokdong13.toml
```

결과는 `output/<파일명>/`에 생성됩니다.

| 파일 | 내용 |
|---|---|
| `report.md` | 블로그 구성 그대로의 원고 초안 (기본정보 → 대지지분·시세 → 정비계획 → 수지표·비례율 → 분담금표 → 시나리오 → 민감도 → 마무리). `✍️ [작성]` 부분만 직접 채우면 됨 |
| `tables.xlsx` | 모든 표를 시트별로 정리. 네이버 에디터에 복사·붙여넣기용 |
| `sens_ratio.png` | 평당공사비 × 일반분양가 비례율 민감도 |
| `sens_contrib.png` | 같은 조건의 기준 평형 분담금 민감도 |

### 새 단지 분석 순서

1. `analysis/complexes/mokdong13.toml`을 복사해 이름을 바꿉니다. 예: `sanggye5.toml`
2. 정비구역 지정 고시문과 시세를 보고 숫자를 고칩니다. 각 항목 설명은 파일 안 주석에 있습니다.
3. 위 명령으로 실행합니다.

### 계산 방식

- 비례율 = (총수입 − 총사업비) ÷ 종전자산평가액
- 권리가액 = 종전자산평가액 × 비례율
- 분담금 = 신축 조합원분양가 − 권리가액 (음수는 환급)
- 분양가 = 공급면적(평) × 평당 분양가 × 평형별 차등계수, 면적 환산은 ㎡ × 0.3025
- 공사비 = 연면적(평) × 평당공사비. 금융비·예비비 등은 `elasticity`만큼 공사비 변동을 따라감
- 금액 단위는 모두 천원 (블로그 수지표와 동일)

예시 파일은 [사업성분석#21] 목동 13단지 글의 수치이며, 기본 비례율 99.49%가 블로그와 일치합니다.
