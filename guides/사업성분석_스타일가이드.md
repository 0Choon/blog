# [사업성분석] 시리즈 스타일 가이드

> Choon's Note 네이버 블로그 `[사업성분석#11]~#20` 10편(2026.09~11)을 분석해 정리한 작성 규칙.
> 새 사업성분석 포스팅은 이 가이드를 따른다.

## 1. 제목·메타

- 제목: `[사업성분석#NN] {단지명} 아파트 재건축 분담금, 분양가, 비례율, 공사비&분양가 민감도`
  - 민감도 분석이 없으면 `… 분담금, 분양가, 비례율`까지만
- 카테고리: `사업성 검토`
- 회차 번호는 직전 글 +1 (현재 최신: #21 목동12단지)

## 2. 문체·톤앤매너

- **평서형 문어체(~이다/~한다)**. 합니다체·해요체를 쓰지 않는다.
- 단정하기보다 추정형으로 마무리한다: `~로 보인다`, `~것으로 예상된다`, `~듯 하다`, `~지 않을까 한다`, `~것 같다`
- 분석을 시작할 때 `~정리를 해보려 한다`, `차근차근 분석을 해본다`, `세부 분석을 해보려 한다`
- 1인칭 경험을 가볍게 섞는다: "약 3년 전 집을 알아보던 와중 집구경도 해 보았던 단지이다", "지난번 ○○를 분석하면서 주변 단지들을 보다보니 눈에 띄었던…"
- 이전 분석 단지와 비교하며 시리즈의 연속성을 살린다: "앞서 분석했던 하계 장미 단지와 유사한 모습을 보인다"
- 전문가 시각의 평가를 짧게 덧붙인다(설계·배치, 공사비 적정성, 조합 내홍, 통합/단독 재건축 등).
- 이모지는 쓰지 않는다. 기호는 `-`(항목), `•`(요약 bullet), `▶`(시나리오 결과), `※`(핵심 코멘트), `*`(가정·각주), `[대괄호]`(소단락 제목)만 쓴다.
- 문단은 2~3문장으로 짧게 쓴다. 숫자 결론(**총 종전자산가액 X원 수준** 등)은 볼드로 강조한다.

## 3. 표기 규칙

- 면적: `95,146.7㎡ (28,781.9평)`처럼 ㎡와 평을 병기한다.
- 금액: 표는 **천원 단위**(`1,714,246,800`), 본문은 억원(`1조 7,142억원`, `5.6억원`)으로 쓴다.
- 단가: `4,600만원/평`, `평당 900만원`
- 준공일: `1988. 5. 13. (39년차)`
- 출처 캡션: `출처 : 영등포구`, `(출처 : 서울시 정비사업 정비몽땅)`
- 공고 인용: `서울특별시 노원구 공고 제2026-1236호에 따라 …`. 첨부파일(공람공고문 PDF)과 관련 기사 링크 카드를 넣는다.

## 4. 글 구성 (A형: 자체 추정. 정비계획 세부수치가 없을 때)

**1) {단지명} 기본정보**
- 지도 카드(단지명 + 주소)
- `- 준공일 : / - 세대수 : / - 용적률 : / - 평형대 : …평형(공급평형) / (- 토지등소유자수 :)`
- 도입 2~3문단: 입지(역·공원·학교) → 추진 단계 → 분석 동기("인터넷에서 ○○ 추정치가 다수 보이는데 과연 적정한 금액대일지…")

**2) 대지지분, 시세**
- `- 대지면적 : ㎡ (평) / 지번`
- 표 제목: `타입별 전용면적, 공급면적, 세대수, 대지지분, 현재시세(KB기준의 NN%) 표`
- 컬럼: `타입 | 전용면적 | 공급면적 | 세대수 | 대지지분(평) | 현재시세(천원)`. 마지막에 `상가 등`, `합계` 행
- 대지지분 코멘트 1~2문장
- `예상 조합원 수 : N명 (공동주택 세대수 가정)` 또는 `토지등소유자 수 : N명 (정비몽땅 게시 기준)`
- 시세 반영률은 KB시세의 84~95%로 잡고, "재건축 프리미엄을 배제하기 위해"라는 이유를 적는다.
- **총 종전자산가액은 ○조 ○억원 수준**으로 나온다. 상가 등 소유주는 청산 대상으로 가정한다.

**3. 재건축 예상 계획**
- 근거: 지구단위계획 고시 또는 정비기본계획(변경) 열람공고(첨부)
- `[기본 가정]`/`[기본 개요]`: 전체 사업면적, 사업면적, 기부채납(용도), 국공유지, 계획 용적률(근거: 법적상한 + 역세권 특례 등)
- `*` 각주: 상한용적률 산정 근거(기부채납 환산, 사업성 보정계수, 역세권특례 완화분의 70% 등)
- 구성평형, 공공주택 세대수, 주차대수(세대당 약 1.5대)
- `[사업 계획]`
  - `1) 공동주택`: `- 총 세대수` / `- 전용59㎡ : 450세대 / 조합원 220세대 + 일반분양 109세대 + 공공임대 121세대` / `* 조합원 분양 세대는 임의로 구분함`
  - 신축 타입표: `타입 | 전용면적 | 공급면적 | 세대수 | 대지지분(평) | 비고` + 합계
  - `※` 코멘트(일반분양 물량, 소형 비중 등)
  - `2) 단지내 상가` 또는 `2) 비주거(상가 및 오피스텔)`: 지상 연면적 잔여분

**4. 사업성 분석**: `[사업비, 비례율 분석]`
- 가정 bullet:
  - `- 일반분양가 : N만원/평` + `* 인근 ○○ N만원 ~ ○○ N만원 수준을 고려하여 책정`
  - `- 조합원분양가 : N만원/평 (일반분양가 75~90%)`
  - `- 상가매각가 : 2,000만원/평`
  - `- 평당공사비 : 850~1,000만원`
  - `- 공공주택은 기본형 건축비로 책정하여 매각`
  - `- 공사기간 : N개월 (사유)`
  - `- PF 금리 : 5.5~6.0%`
  - `- 총 사업비 : ○조 ○억원`
- 2열 표 `사업비 | 분양수입` (천원)
  - 사업비: 철거비, 청산금(상가), 공사비, 기반시설(공원 등)/공공시설, 용역비, (일반)분양경비, 기타(부담금,예비비), (현금기부채납), PF금융비, 사업비 합계
  - 수입: 조합원분양, 일반분양, 단지내상가 분양/비주거시설, 공공주택 매각, 공공분양 부속토지, 총수입 합계
- `비례율 계산` 표: 각 수입 항목, 종전감정평가액, 총사업비 → **비례율 XX.XX%**

**5. 예상 분담금 (및 비례율 민감도)**
- `[평형별 추정 분담금]`: 종전 타입(행) × 신축 타입(열) 분담금 표. 환급 구간 유무를 언급한다.
- `[공사비, 분양가 변동에 따른 비례율 민감도]`: 공사비는 기준의 95~115%, 분양가는 95~110% 범위로 잡은 매트릭스. 상방/하방 중 어느 쪽이 열려 있는지 근거를 쓴다.

**6. 마무리**
- 현재 매물 호가/실거래 → 진입 비용 계산 bullet
  - `• 24평 매입→전용84㎡분양 : 매입가 8.0억원 + 분담금 5.6억원 = 13.6억원 (평당 4,000만원)`
- 일반분양가·준공 후 예상 시세와 비교한다(대출이자·세금은 별도).
- 신규 진입자에게 신중한 판단을 당부한다. 시장 전망은 단정하지 않는다("각자의 현명한 판단이 필요할 것이다").
- 면책 문구(고정):
  > *개인적으로 분석해 본 내용으로서, 여러 가정 요인들이 많기에 참고용으로만 봐주시길 바라며, 혹 틀린부분이나 보완할 부분에 대해 댓글 등으로 의견 주시면 감사드리겠습니다.

## 5. 글 구성 (B형: 공식 정비계획 검증. 공람·고시에 추정 비례율이 있을 때)

예: #14 올림픽훼밀리타운, #15 올림픽선수기자촌, #17 신길우성1차, #19 상계보람

1. 기본정보(+추진 경과, 내홍 등 이슈 기사)
2. 정비계획(안) 요약: 총 세대수(임대), 신축평형, **추정 비례율**, 종전 자산가액, 총 지출, 총 수입, 평형별 추정시세, 조합원 추정분양가, 공식 추정 분담금 표
3. 공사비·분양가 역산과 평가
   - 공사비 = 총사업비 × 80~82% ÷ 총 연면적(지상: 용적률 역산, 지하: 주차대수 × 42㎡/대) → `※ 평당 추정 공사비 : N만원`
   - 분양가 = 조합원분양가 ÷ 공급평 ÷ (조합원분양가 비율) → 타입별 나열 후 `※ 추정 일반 분양가`
   - 분양가상한제 지역이면 택지비(공시지가 × 1.6~1.8) + 기본형건축비로 상한 분양가를 검토한다.
   - 인근 분양·실거래 사례로 적정성을 평가한다("평당 830만원은 다소 낮은 감이 있어보인다").
4. 민감도: `▶ 공사비 5% 절감 : … / 비례율 NN%` 형식, `• 요약` bullet
5. 마무리 + 면책 문구
